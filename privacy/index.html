ATOM · OFFICIAL POLICY

Privacy Policy

Effective date: November 24, 2026 · Last updated: November 24, 2026

1. Overview

This Privacy Policy explains how Atom (“the Bot”) handles information when it is used in a Discord server. Atom is a multipurpose bot. Information described below is processed for operating, maintaining, and providing Atom’s bot features.

2. Information Atom may store

Depending on which features are enabled or used, Atom may store the following information in its SQLite database:

  • Server ID: identifies the Discord server using Atom.
  • Server owner ID: identifies the server owner for owner-level settings or permissions.
  • User ID: identifies users who interact with relevant Bot features.
  • Server configuration: settings and preferences configured for the server.
  • Audit records: records related to relevant server events and Bot activity.
  • Punishment records: moderation-related records, such as actions recorded by supported features.
  • Message content: message text may be processed or stored where needed for features that inspect, moderate, log, or respond to messages.

3. How information is used

Information is used to operate Atom and its features, apply server-specific settings, provide moderation and security functions, maintain relevant records, troubleshoot issues, and respond to support or data requests. It is not collected for unrelated advertising or profiling purposes.

4. Storage

Atom uses an SQLite database for the information described in this Policy. The database is used by the Bot’s hosting environment. The exact hosting location, backup arrangements, and infrastructure-level retention depend on the service used to run Atom.

5. Sharing and disclosure

Information is used for Atom’s operation and is not sold. It is not intentionally disclosed to unrelated parties. The hosting provider or infrastructure services used to run the Bot may technically process or store information as necessary to provide that hosting. Discord separately processes data under its own policies and terms.

6. Retention and deletion

Information may be kept while it is needed for the relevant Bot features, configuration, audit history, or punishment records. A fixed automatic deletion period has not been specified. Removing Atom from a server does not necessarily erase records already stored in the SQLite database. To request access to or deletion of relevant data, contact us using the details below and identify the server or user record concerned.

Do not send passwords, authentication tokens, or other account secrets in a data request. We may need enough information to identify the relevant server or record and verify that the request is authorized.

7. Security

Reasonable measures should be used to protect the Bot’s database and hosting environment. No electronic storage or transmission method can be guaranteed to be completely secure.

8. Your choices and server responsibilities

Server owners and administrators control whether Atom is added, which features are enabled, and which permissions are granted. They should inform their members about relevant moderation, logging, and message-processing practices where required by law or their community rules.

9. Children and age requirements

Atom is provided through Discord and is not designed to bypass Discord’s age requirements. Users must meet the minimum age requirements that apply to their use of Discord and comply with applicable law.

10. Changes to this Policy

This Policy may be updated as Atom’s features or data practices change. The updated version will be published on this page with a revised date.

11. Contact and data requests

For privacy questions or requests concerning Atom data, email atomdevelopment.py@gmail.com or contact us through the Atom Support Server.
